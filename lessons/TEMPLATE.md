# Lesson entry template

Copy this block to the top of `LOG.md`. Newest first. Keep it to ten lines.

```markdown
### YYYY-MM-DD — <one line, names the thing that happened>

**What happened.** Two sentences. Fellow or system named. In their words, not studio jargon.

**Evidence.** What was actually observed, with its ladder rung. `[Fact]` / `[Assumption]` / `[Hypothesis]`.

**Cost.** What was lost — weeks, a pilot, credibility, a wrong build. A number if there is one.

**Lesson.** The decision rule that would have changed the outcome. One sentence.

**Changes.** Which rule in `GOLDEN_RULES.md`, which skill, or which default now differs. Or: none yet, and why.
```

Three tests an entry must pass — specific, costly, actionable. Detail in
[`skills/lessons/SKILL.md`](../skills/lessons/SKILL.md).
