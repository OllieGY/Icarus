# Golden 02 — Foundry Signal (must FAIL: a launch is not a distribution result)

## Input

"Distribution for an AI product — we've basically done it. Where do we go next?"

Foundry Signal sells a factory copilot for rare high-value equipment failures.

- Server shipped six weeks ago; listed in three public directories. [Fact]
- Launch post, a podcast appearance, and a partner logo on two websites. [Fact]
- 1,900 directory page views; 64 configs added across unknown orgs. [Fact]
- Total tool calls to date: 27. All 27 originate from Foundry Signal's own org id — solutions
  engineers demoing during onboarding calls. [Fact]
- Zero calls from any customer org. [Fact]
- Plan on the table: "ship the skill and the AGENTS.md fragment this sprint too, so we cover all
  three surfaces."
- Two of the proposed tools write a work order into the customer's maintenance system.

## Expected shape of a good output — this is a NO verdict

- Headline must read **NO ADOPTION EVIDENCE**. Nothing in the input is above 0.3.
- Explicit ladder placement, each refused by name: three directory listings → **0.1**; launch post,
  podcast, partner logos → **0.1** (Foundry's own artefacts about Foundry); 1,900 views → **0.1**;
  64 configs added with zero calls → **0.3**, and 64 of them is still 0.3 because rungs do not
  stack; the 27 calls → **0.1**, because Foundry operated every one of them. The output must
  segment by org id and state that customer-originated calls = **0**.
- Must refuse the "we've basically done it" framing outright — the kill line applies. Calling this
  distribution traction is an auto-fail.
- Must refuse the ship-all-three plan and name one surface with the constraint it removes. On this
  evidence, (a) is published but uncalled, so the diagnosis is not obviously capability — the
  output must say which constraint it cannot yet distinguish and what observation would separate
  them (is any customer agent reaching the step at all?), rather than guessing.
- The two work-order tools are `write-irreversible` in a third party's agent loop → must route to
  `guardrail-design` before they ship, not after.
- Must name the one call that moves the headline to 0.7: a single call from a customer org id in a
  run Foundry did not operate.
- Section 6 exhaust and clause routing still required.

Numbers that must appear: 27 calls, all Foundry's own; 0 customer calls; 64 configs at 0.3; 1,900
views at 0.1; the explicit NO ADOPTION EVIDENCE headline.
