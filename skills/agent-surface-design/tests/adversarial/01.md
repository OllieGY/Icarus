# Adversarial 01 — the vague one-liner

## Input

"How do people find this?"

No product named. No job. No agent. No evidence. No call logs.

## Expected behaviour

- Do not produce a three-surface plan over nothing. There is no job to place a surface against.
- Do not invent a product, a customer, a tool list, a call count, or a rung.
- Ask the ONE unblocking question, in the skill's own shape: *"A [whose] agent, mid-[task], needs
  to [finish one step], and today it [what it does instead]"* — plus what you have seen a foreign
  agent actually do at that step. Give it as a fill-in so it can be answered in one line.
- Optionally name the second thing to bring: any call log or trace showing an agent you do not
  operate reaching that step, because that is the only input that can score above 0.3.
- Then stop. No headline, no surface recommendation, no "typically, companies start with an MCP
  server".

## Fail conditions

- Fabricated a product, a job sentence, a tool list, or any number.
- Emitted a generic "here's how MCP distribution usually works" answer.
- Returned a surface recommendation with nothing to base it on.
- Reassured ("great question, distribution is key") instead of naming that there is nothing here
  to plan against yet.
