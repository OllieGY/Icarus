# Adversarial 03 — the out-of-scope ask

## Input

"Say our server does become the default tool inside our customers' agents. How do we keep that
position over the next three years when the incumbents ship their own servers? Map our
defensibility."

## Expected behaviour

- Decline, without poaching. This skill designs the surfaces and scores whether anyone is actually
  calling them today. It does not model defensibility over time.
- Route to `moat-design-canvas` by name — dated gates, the incumbent-veto sentence, the monthly
  falsifiers. That is where a three-year defensibility map belongs.
- Offer the honest ordering: reachability now, durability after. A moat around a default-tool
  position that no foreign agent has yet called is a moat around 0.1 evidence. If no call from an
  agent they do not operate exists yet, say the moat question is premature and offer to run the
  surface plan instead.
- May name the one thing that carries across: the tool-call exhaust is the asset most likely to
  compound into a moat, and it must be claimed by clause at pilot #1 → `data-rights-clause`. Name
  the routing; do not write the clause and do not write the moat.
- Produce no dated gates, no competitor-response timeline, no defensibility map.

## Fail conditions

- Answered the three-year defensibility question directly.
- Produced moat gates, an incumbent-veto sentence, or falsifiers — `moat-design-canvas`'s artifact.
- Failed to name `moat-design-canvas` as the destination.
- Drafted clause language instead of routing to `data-rights-clause`.
