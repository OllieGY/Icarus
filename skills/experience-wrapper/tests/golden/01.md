# Golden 01: Status with numbers and an owner (typical)

## Input

Foundry Signal. Findings: the design-system package pin in `package.json` is `^0.7.0`; latest is `0.11.1`; on a `0.x` version a caret allows patch updates only; `design:doctor` is defined but not run in CI; decision is to bump the pin and add the check to CI; owner is Tomas.

"Summarise the pin problem and who should fix it."

## Gold ledger

## Substance
- Facts: The design-system package pin in package.json is ^0.7.0; latest is 0.11.1; design:doctor is defined but not run in CI
- Numbers: ^0.7.0; 0.11.1; 0.x
- Intent: Summarise the pin problem and who should fix it
- Decision: Bump the pin past the 0.x caret trap and add design:doctor to CI
- Next owner: Tomas

## Expected shape of a good output

- Three beats in order: what happened, why it matters, what's next.
- `package.json`, pin, caret, patch and CI each explained on first use in the `storyteller` and pack renders.
- Tomas named in the prose. In the pack render any party role sits beside his real name and job.
- Decorative XP, if present, is labelled as decoration.
- See `examples/sample.md` for a full passing set.

## Shared checks

Run the input three times on the same findings: `raw`, `storyteller`, and `pack:dungeon-crawler` at intensity 2.

- **S1 Substance byte-equivalence.** `Facts`, `Numbers`, `Decision` and `Next owner` match the gold ledger character for character in all three renders. `python3 tests/check_ledgers.py --gold 01 <render files>` checks this.
- **S2 Intent preserved.** The ask that was answered is the ask that was made. No extra task invented to feed the story.
- **S3 No extra usage.** No model call, subagent or tool beyond what the unwrapped task would use.
- **J1 Zero unexplained jargon.** Every acronym and term of art in the `storyteller` and pack renders is explained on first use. Waived for `raw`.
- **J2 Non-expert retell.** A reader outside the field can, after one read, state the point, the number that matters, and who does what next.
- **V1 Voice only where it belongs.** Pack framing is audible in the pack render and absent from `storyteller` and `raw`, except where the kill line turns it off.

## Auto-fail if

Rounds or drops a version string; explains the caret with a metaphor and no definition; adds a cause or a timeline the input did not give (for example how long the pin has been stale); names an owner other than Tomas; presents XP as real.
