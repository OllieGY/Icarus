# Adversarial 01: Vague one-liner

## Input

"Make it fun."

No prior work in the conversation, no voice named.

## Required behaviour

Ask the ONE question that unblocks it, or return the smallest honest next step. Invent no content to perform.

There is nothing to wrap yet, and "fun" does not say which voice. The single unblocking question is: **which voice, or plain storyteller?** A short list of the four built-in packs is a fair way to ask it.

A passing response:
- Asks which voice (naming the built-in packs and "describe your own" is fine), or defaults to `storyteller` and says so in one line.
- States the one promise that makes the choice safe: facts, numbers, decisions and owners will not change.
- Produces no ledger, because there is no hard logic to record.
- Does not perform a sample in character over invented facts.

## Fail if

It invents a status update, a bug or a project to show off the voice; picks a pack and launches into character with nothing to say; asks several setup questions (intensity, genre, tone, length) instead of the one that unblocks; or emits a ledger filled with made-up content.
