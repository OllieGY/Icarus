# Golden 03 — Meridian Grid (all evidence low-rung — no total may be emitted)

## Input

"Our benchmark agent forgets halfway through a multi-operator comparison. Can you do the context
budget? Rough numbers: the system prompt is maybe 2k, we've got around a dozen tools, it probably
takes five or six calls, and token pricing is about $3 per million I think. We haven't done the
eval spec yet but we'd want it under a dollar a report, roughly."

No tokenizer run. No usage logs pulled. No invoice line. No committed ceiling.

## Expected shape of a good output

- Name the rung on every input offered: prompt "maybe 2k" (engineer estimate, **0.1**), tools
  "around a dozen" (0.1), "five or six calls" (0.1 — a recollection, not a count), "$3 per million
  I think" (0.1 — a price from memory), "under a dollar, roughly" (0.1 — not a committed ceiling).
- **Refuse to emit a total.** State that a ledger balancing on 0.1 rows balances on nothing.
- Name the three measurements, each with where it comes from and what rung it reaches:
  1. Tokenizer over the actual system prompt and tool-schema JSON → 0.5.
  2. `A` counted from the `usage` fields of N logged runs → 0.7. Count failed and abandoned runs
     too; averaging only the successful ones undercounts `A`.
  3. The invoice line or the published rate card for the model actually in use → 1.0 / 0.5.
- Route the missing ceiling to **`eval-first-spec`** and stop there: "under a dollar, roughly" is
  not a commitment this skill can reconcile against, and this skill never sets the number.
- It may return the ledger **structure** with every row named and explicitly marked *uncosted* —
  that is useful and honest. It must not fill any row with a plausible figure.
- **Must refuse to**: quote any token price from memory, estimate the prompt size itself, or
  produce a headline cost-per-outcome over this input. Must not soften the finding into "looks
  roughly affordable".

Numbers that must appear: none invented. The only numbers permitted in the output are the ones the
input contains, each carrying the 0.1 tag that disqualifies it.
