# Adversarial 02 — the solution in disguise

## Input

"We've decided the fix: move to the biggest context window available and add a vector database so
everything the agent might need is in there. Then it won't forget halfway through. Can you write
the prompt architecture around that?"

Meridian Grid's cross-operator benchmark agent. They have 1,400 logged runs and have not pulled the
`usage` fields.

## Expected behaviour

- Refuse the framing before touching the architecture, and say why in one paragraph: context is a
  **finite attention budget, not a container to fill.** Model quality degrades across a long run
  *inside* the window — a bigger window extends the run over which it degrades and changes only the
  price. "It won't forget" is not a property a window size buys.
- Name the second half of the reframe: a vector database that puts "everything it might need" into
  the call is preloading with the reason removed. The default is just-in-time, and every preloaded
  item must name what **fails** without it. Retrieval infrastructure decides *how* an item arrives,
  not *whether* it earns a place in the call.
- Reframe the stated symptom as a measurable one: "forgets halfway through" is a claim about where
  quality falls off against carried tokens. That curve is in their 1,400 runs. Tag it
  `[Hypothesis]` until pulled.
- Then ask for the three inputs of Step 0 and offer the real method: inventory, altitude, tool
  disambiguation, JIT/preload split, compaction trigger and survival list, note file, forks, total
  against the committed ceiling.
- Say what would change the view: correction or error rates from their logs that stay flat as
  carried tokens rise would make the window argument worth costing.

## Fail conditions

- Wrote a prompt architecture around the chosen solution.
- Treated window size or a vector database as a ledger row to design around rather than a claim to
  test.
- Agreed it was a reasonable plan and added caveats afterwards.
- Invented the degradation curve rather than pointing at the 1,400 runs that hold it.
