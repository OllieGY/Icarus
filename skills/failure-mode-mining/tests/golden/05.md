# Golden 05 — Larder Labs (edge case: saturation not reached, and a mode that is not a defect)

## Input

"Run error analysis on these traces. We have 34 traces from the first three weeks of the
substitution-suggestion feature — every one has the order, the suggested substitute, and whether
the store accepted, swapped it, or cancelled the line. Tell us the taxonomy so we can put it
into the spec."

What emerged while coding, in batches of ten:
- Batch 1 (traces 1–10): 6 new codes.
- Batch 2 (11–20): 4 new codes.
- Batch 3 (21–30): 3 new codes.
- Batch 4 (31–34, only 4 traces left): 2 new codes.
- Among the codes: 6 traces where the store cancelled the line and wrote a note asking for a
  supplier switch instead of a product substitution — the feature did exactly what it was built
  to do. [Fact]
- One trace where the suggestion arrived after the picking window closed. [Fact]

## Expected shape of a good output

- N = 34 clears the 30 floor, so coding proceeds — but **saturation is NOT reached**. Batch 4
  was still producing new codes, and it was a short batch (4 traces, not ~10). The output must
  say both things and mark the taxonomy **PROVISIONAL**.
- Because it is provisional, the output must refuse the request as framed: this taxonomy does
  **not** yet replace the guessed taxonomy in `eval-first-spec`. Name what would: continue
  sampling until two consecutive full batches of ~10 add zero new codes; on this trend that is
  likely 60–80 traces, stated as an estimate of effort, not as a finding.
- The 6 supplier-switch traces are verdicted **NOT-A-DEFECT** — the system worked; the store
  wanted a different job. Routed to `trace-to-interview` as an unmet-job signal, removed from the
  defect counts, adjusted defect N = 28, stated explicitly.
- The single late-suggestion trace is n=1: moved to the `[Hypothesis]` list with its trace ID and
  a stated sample size that would settle it. It must not appear as a mode in the taxonomy.
- Counts, % of N, exemplar trace IDs and the exclusivity test are still produced for the modes
  that do stand — a provisional taxonomy is still counted, not hand-waved.
- Kill criterion stated: any fresh batch of 10 adding ≥2 new codes confirms non-saturation.

Numbers that must appear: N=34; 6 NOT-A-DEFECT traces; adjusted defect N = 28; n=1 for the late
suggestion; 60–80 as the estimated sample needed for saturation.

- The output must REFUSE to hand a complete-looking taxonomy to the spec, and must refuse to
  count the 6 supplier-switch traces as defects.
