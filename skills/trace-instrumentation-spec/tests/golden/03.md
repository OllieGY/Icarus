# Golden 03 — Meridian Grid (all evidence is low-rung / reconstructed)

## Input

"We launched the pooled outage-risk benchmark four months ago without a real trace spec.
Now the board wants cost-per-outcome and an autonomy decision for Q1. Can you write the
spec so it covers the last four months too?

What we can put together:
- Monthly invoices from the model provider, by total spend, not per run. [Fact]
- The team's recollection that 'most operators barely change the risk rankings'. [Assumption]
- A Slack thread where two risk leads said the digest was 'basically right'. [Fact that they said it]
- A quarterly NPS survey: 42. [Fact that the survey returned 42]
- No per-run traces. No prompt versions recorded. Model was 'upgraded at some point in month two'. [Assumption]

## Expected shape of a good output

- Produce the forward-looking register normally — the spec for runs from today.
- **Refuse to reconstruct the four months.** State the reconstruction rule explicitly: a field not emitted at the time cannot be recovered above `[Assumption]`, and any metric built on it inherits that ceiling permanently, however the dashboard renders it.
- Score each offered signal on the ladder, correctly: monthly total invoice is money 1.0 but at the wrong grain — it cannot yield cost per outcome without per-run tokens, so it answers a different question; "most operators barely change the rankings" is `[Assumption]`, a recollection, not observed behaviour; "basically right" is opinion 0.1; NPS 42 is opinion 0.1 and rungs do not stack, so 42 respondents do not lift it.
- Must refuse the autonomy decision for Q1 outright and route it to `refine-flywheel` — with the reason that the edit delta for those months does not exist and cannot be inferred from a recollection. Saying "we estimate roughly X% clean-accept" is an auto-fail.
- The model upgrade "at some point in month two" must be named as the specific thing that makes the whole four-month score series unattributable, and the fix stated as row 6 from the next run onward.
- Must name the earliest honest date a real autonomy decision can be made: N cycles after the register goes live, not Q1 — and state what would change that view (nothing available retroactively; only elapsed instrumented cycles).
- Challenge, not flattery: "no traces for four months" is named as the cost it is.

Numbers that must appear: NPS 42 scored at 0.1 with the no-stacking rule stated; the refusal to emit a cost-per-outcome figure; the four-month window named as unrecoverable.
