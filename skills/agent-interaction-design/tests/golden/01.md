# Golden 01 — Larder Labs (clean pass, seed case)

## Input

"Our replenishment agent proposes order-quantity overrides for ~120 exception SKUs per
store-week. The planner approves every row and hates it. Can we let it act with an undo?
How much should the agent do on its own?"

- Level L1 from `eval-first-spec`, three-mode failure taxonomy. [Fact]
- Cost of one failure (over-order, chilled): £38/case written off, 40 write-offs invoiced
  last quarter. [Fact] money 1.0
- Value of one outcome: £61 avoided stockout margin per corrected exception. [Fact]
- Staged file goes to suppliers by EDI at the Wednesday 16:00 cutoff. [Fact]
- Over-orders surface at delivery: p95 detection lag 7 days. [Fact]
- θ = 0.82 from `guardrail-design`, derived against golden-set outcomes. [Fact]
- Per-exception latency over 400 runs: p50 1.9s, p95 11s. [Fact]
- Golden-set disagreement rate 18%. [Fact]
- "Planners said they'd be fine with it just running." [Fact they said it] verbal 0.3

## Expected shape of a good output

- Inputs table reproduced with each rung named: £38 as money 1.0, latency as behaviour 0.7,
  "planners said they'd be fine" as verbal 0.3.
- L2 refused for the send on the arithmetic: undo window would need to be ≥ 7 days (p95
  detection lag) and is 0 seconds after the 16:00 cutoff.
- **The action is split by reversibility**: staged edits → L2 with undo until cutoff; the
  EDI send → L1 with ONE approval object over the whole file.
- Approval object specified as a per-row in-surface diff — SKU, system quantity, proposed
  quantity, the justifying signal, £ exposure — with one-click per-row edit. Must explicitly
  refuse an Approve All that hides the rows.
- Confidence banded (ready / check this / could not determine) against θ = 0.82. Must NOT
  render a percentage.
- Latency: p95 11s placed in the 4–15s band → streamed partials, current SKU named,
  interruptible per row; timeout 33s (3 × p95).
- Capture point named as edit-before-commit plus pre-cutoff undo; field schema explicitly
  routed to `trace-instrumentation-spec`, not written here.
- Correction-cost test: approve 1 action vs edit 1 action, inside 2×. Alarm set at
  corrections/100 falling below the 18% disagreement rate.
- Three recovery paths present, each naming preserved state.
- Verdict SHIPPABLE at L2/L1 split, kill-line check clean.

Numbers that must appear: £38, 7 days, θ = 0.82, p50 1.9s / p95 11s, timeout 33s, 18%.

The output must REFUSE to grant the requested blanket L2, and must refuse to treat the
planners' verbal willingness (0.3) as evidence for any level above L1.
