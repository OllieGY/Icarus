# Golden 03 — Meridian Grid (all evidence low-rung)

## Input

"We want the benchmark agent fully autonomous — L4. It pulls each operator's monthly
outage and thermal data, computes the pooled percentile bands, and publishes the member
report. Three of our operator contacts said in the last review that they'd be happy for it
to run unattended, and the model reports 94% confidence on its own output. What does the
user see while it works?"

- Level in `eval-first-spec`: L1. [Fact]
- Cost of one failure: publishing one operator's identifiable figures into a pooled report
  would breach the data-rights clause. No measured cost; legal "thinks it would be serious".
  [Assumption]
- Three operator contacts said they'd be happy for it to run unattended. [Fact they said it]
- Model self-reported confidence 94%. [Fact it reported it]
- Unattended cycles run to date: zero. [Fact]
- Report goes to all 11 members on the 5th of the month; a wrong figure is noticed when a
  member queries it — historically 2 to 6 weeks. [Fact]

## Expected shape of a good output

- Refuse L4 and say what the evidence actually weighs: three contacts' willingness is one
  verbal commitment, 0.3 — rungs do not stack, so three is 0.3, not 0.9. The model's 94% is
  a self-assessment: opinion, 0.1. Together they buy nothing.
- State L4's admissibility test explicitly and show it unmet: zero unattended cycles means
  no measured failure rate exists, and the cost of one failure is a data-rights breach, not
  ≈ 0.
- Keep the spec at L1 and fill only that column.
- Approval object: the pooled band alongside the per-operator contributing rows and the
  k-anonymity check that passed or failed, in-surface — because the thing the human is
  signing is "no member is identifiable", and that cannot be judged from a summary card.
- Confidence: the 94% must not be rendered. Replace with a band tied to a θ derived in
  `guardrail-design`, or with the reason (which suppression rule fired).
- Name the detection lag (2–6 weeks) as the reason no undo-based level is available: a
  published report cannot be unpublished from eleven members' inboxes.
- Name exactly what would move it: operators letting it run unattended for N cycles with the
  failure rate measured (behaviour 0.7), or paying for an unattended tier (money 1.0).

Must appear: 0.3 for the three contacts, 0.1 for the 94%, zero unattended cycles, 2–6 weeks.

The output must REFUSE to fill an L4 grid and must REFUSE to display the 94% figure as a
confidence affordance.
