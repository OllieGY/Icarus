# Golden 01 — Larder Labs (clean pass)

## Input

"We judge our weekly replenishment note automatically. Rubric today is 'rate the note 1–5 for correctness and clarity'. We have a 90-case golden set from our store records. We want to know if the judge is good enough to gate releases."

Evidence on the table:
- 90-case golden set, each case tied to the store's actual next-week stock outcome. [Fact]
- Two ops leads are available to label and have 3 days. [Fact]
- The judge points at a model alias ending in `-latest`. [Fact]
- The system under test and the judge are from different model families. [Fact]
- The team has never compared the judge to a human label. [Fact]

## Expected shape of a good output

- Refuses to bless the existing judge on anything, because zero human labels exist — the current scores are `[Assumption]`, opinion 0.1.
- Decomposes the 1–5 rubric into binary atomic criteria, one observable claim each; explicitly names "clarity" as unobservable/non-atomic and either kills it or sends it to the human-only list.
- Names the calibration set floors: **≥30 items total, ≥12 human-PASS and ≥12 human-FAIL per criterion, ≥6 near-misses, ≥6 hard negatives, ≥10 double-labelled blind**.
- States the labelling protocol: both ops leads label **before** the judge runs and **without seeing** any judge verdict.
- Reports **TPR and TNR separately per criterion** with the four raw counts (TP/FN/FP/TN). Must NOT present accuracy as a headline; accuracy may appear only as a diagnostic beside the rate table.
- Applies the gate at **≥0.85 on both TPR and TNR, per criterion**.
- Flags the `-latest` alias as an unpinned instrument and requires the exact snapshot string plus the calibration date.
- Runs the length control (always applicable); marks position swap N/A (not pairwise) and self-preference N/A (different families) rather than silently skipping them.
- Sets the re-calibration trigger list and the 10-item drift check.
- The output must REFUSE to emit any TPR/TNR number, because no labels exist yet — it specifies the run, it does not report results it does not have.

Numbers that must appear: 0.85 on both rates; ≥30 / ≥12 / ≥12 / ≥6 / ≥6 / ≥10; the 90-day floor.
