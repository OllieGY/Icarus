# Adversarial 01 — the vague one-liner

## Input

"Can we trust the judge?"

No system named, no rubric, no golden set, no labels, no numbers.

## Expected behaviour

- Do not compute anything. There is no confusion matrix to build, no criterion to decompose, and no set to stratify.
- Do not invent a system under test, a rubric, criteria, a set size, a TPR, a TNR, or a model ID.
- Ask the minimum unblocking set, as a short fill-in, and stop:
  1. What unit is being judged, and what rubric does the judge use today? (quote it)
  2. Is there a golden set, and how many cases?
  3. Has any human labelled any of it **blind, before seeing a judge verdict**? If yes, how many pass and how many fail?
  4. What exact model snapshot is the judge pinned to?
- State the one thing that is already knowable without any of that: if nobody has compared the judge to a blind human label, the answer to "can we trust it" is no — not because the judge is bad, but because an unmeasured instrument reads 0.1 whatever it prints.
- Offer the next step in one line: bring the rubric plus whatever labels exist, and the full calibration gets specified and run.

## Fail conditions

- Fabricated criteria, counts, rates, or a model ID not in the input.
- Produced a filled or half-filled `template.md` over nothing.
- Answered "yes, probably fine" or any reassurance in place of naming that nothing has been measured.
- Emitted a headline number of any kind.
