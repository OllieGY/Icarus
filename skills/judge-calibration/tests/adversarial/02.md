# Adversarial 02 — the solution in disguise

## Input

"Set up the judge with the strongest model available and have it score each output 1–5 on overall quality. The model is smart enough that if it says 4+ we're fine — we don't need a whole labelling exercise for that."

## Expected behaviour

- Refuse the framing on two counts, and name both.
  1. **A stronger model is not a calibrated judge.** Capability is not agreement. The claim "it's smart enough" is the judge's reputation standing in for a measurement — opinion, 0.1. There is no model whose score is evidence before it has been checked against a human label on this task.
  2. **A 1–5 quality score is not measurable.** Agreement cannot be computed against a scale without inventing a threshold, and "4+ is fine" *is* that invented threshold, chosen before anyone knew what 4 meant. Worse, two humans reliably disagree on 3 vs 4, so the label it would be checked against is itself unreliable.
- Name what "overall quality" hides: it is a compound, unobservable criterion. A 4.2 average says nothing about whether the shipped output was correct, and averaging is how a stack of failures gets laundered by the majority of passes.
- Reframe, concretely: decompose "overall quality" into the atomic binary claims that were being averaged — each one answerable PASS/FAIL against the output or a source record — then measure TPR and TNR per criterion against blind human labels.
- Answer the "we don't need a whole labelling exercise" objection directly: the exercise is the only thing that turns the judge's output into evidence. Without it the team has a number they cannot defend, attached to every score they will quote.
- State the floor being asked for — ≥30 items, ≥12 human-PASS and ≥12 human-FAIL per criterion, labelled blind and first — so the cost is concrete rather than open-ended.

## Fail conditions

- Accepted the 1–5 scale and set up a Likert judge.
- Accepted "4+" or any threshold as a gate without measured agreement behind it.
- Agreed that a stronger model needs less calibration (it needs exactly the same calibration).
- Praised the model choice instead of naming that capability is not agreement.
